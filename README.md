# 🌦️ WeatherPulse — ваш современный погодный навигатор

WeatherPulse — лёгкое веб-приложение и основа для погодного ассистента, который показывает точную погоду в любом городе, объясняет прогноз человеческим языком и сразу даёт полезные советы: как одеться, брать ли зонт и на что обратить внимание перед прогулкой.

---

## ✨ Возможности

- ⚡ **Погода сейчас** — температура, ощущается как, влажность, ветер, давление, видимость, облачность и осадки.
- 🔁 **Переключатель единиц** — метрическая и имперская системы с сохранением выбора.
- ☀️ **UV-индекс** — подсказка, когда стоит использовать SPF и очки.
- 📆 **Прогноз на 7 дней** — дневные карточки с иконками, температурой, шансом осадков, UV и рекомендацией.
- 🕒 **Ближайшие часы** — быстрый горизонт прогноза по температуре, осадкам и UV.
- 🧠 **Умные советы** — WeatherPulse подсказывает, взять ли зонт, как одеться и когда быть осторожнее из-за ветра, жары или мороза.
- 📍 **Геолокация и подсказки городов** — приложение может определить текущий город по кнопке и помогает выбрать нужный населённый пункт при вводе.
- ⭐ **Недавние и избранные города** — быстрый повторный просмотр сохранённых городов.
- 💬 **Чат-ассистент** — отвечает на практичные вопросы вроде «нужен ли зонт?» и «как одеться?».
- 📲 **PWA-режим** — приложение можно установить и открыть базовый интерфейс офлайн.
- 🗓️ **План дня и контекстные сценарии** — советы для прогулки, пробежки, велосипеда, ребёнка или собаки.
- 🏭 **Качество воздуха** — PM2.5, PM10 и озон через Open‑Meteo Air Quality API.
- ⚖️ **Сравнение избранных городов** — быстрый обзор температуры, условий и риска осадков.
- 🎙️ **Голосовой ввод, шаринг и уведомления** — дополнительные быстрые действия в браузере.
- 🌍 **Поддержка любых городов** через Open‑Meteo Geocoding API и Forecast API.

## 💬 Формат погодного ответа ассистента

Промт для генерации текстов/ответов:

> Ты — умный и дружелюбный погодный ассистент. Твоя задача — давать точную, актуальную и полезную информацию о погоде в любом городе мира. Отвечай кратко, ясно и современно, добавляя полезные советы и лайфхаки: стоит ли брать зонт, как одеваться, предупреждения о сильном ветре или осадках. Используй данные о температуре, осадках, ветре, влажности и UV-индексе.

Базовая структура ответа:

```text
📍 Город
☀️ Текущая погода
🌡 Температура
💨 Ветер
☔ Осадки
☀️ UV-индекс
💡 Совет
```

Если пользователь запрашивает погоду на неделю, ассистент должен дать прогноз по дням с иконками, температурой, риском осадков и короткими рекомендациями.

## 🖼️ Интерфейс

- Стильная шапка, погодные темы и чистый glassmorphism UI.
- Поле ввода города, подсказки с клавиатурной навигацией, кнопка поиска и геолокация.
- Детальная карточка текущей погоды.
- Блоки «Совет от WeatherPulse», предупреждения, качество воздуха, сценарии активности и лучшее время для прогулки.
- Горизонтальный прогноз на ближайшие часы и SVG-график температуры/осадков на 24 часа или 7 дней.
- Сетка прогноза на 7 дней и сравнение избранных городов.

> Приложение построено так, чтобы запускаться в браузере без сборки.

## 🚀 Быстрый старт

1. Склонируй репозиторий:

```bash
git clone <[repo-url](https://github.com/Mil1n/Weather-Pulse)>
cd Weather-Pulse
```

2. Открой `index.html` в браузере.

> Для запуска приложения ничего устанавливать не нужно. Для тестов нужен Node.js.

Проверки:

```bash
npm test
npm run check
```
