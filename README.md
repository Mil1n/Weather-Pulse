# 🌦️ Weather Pulse — Modern Weather Dashboard

Красивый и современный веб-сайт для просмотра **подробной погоды по выбранному городу**.

---

## ✨ Возможности

- 🔎 **Поиск по городу** — введи любой город и получи актуальную погоду.
- 🌡️ **Температура в реальном времени** — крупное и заметное отображение.
- 🧭 **Подробные метрики**:
  - влажность
  - скорость ветра
  - давление
  - видимость
- 🌈 **Современный дизайн**:
  - glassmorphism-стиль
  - градиентный фон
  - адаптивная верстка для телефона и десктопа
- 🌤️ **Погодные иконки** (emoji) по погодным кодам.

---

## 🖼️ Превью интерфейса

- Стильная шапка и чистый UI
- Поле ввода города + кнопка поиска
- Детальная карточка погоды с иконками

> Приложение построено так, чтобы сразу запускаться в браузере без сборки.

---

## 🛠️ Технологии

- **HTML5**
- **CSS3** (адаптивность + визуальные эффекты)
- **Vanilla JavaScript**
- **Open‑Meteo API**
  - Geocoding API
  - Forecast API

---

## 🚀 Быстрый старт

1. Склонируй репозиторий:

```bash
git clone <repo-url>
cd Weather-Forecast
```

2. Открой `index.html` в браузере.

> Ничего устанавливать не нужно.

## ❤️ Идея проекта

Сделать быстрый, удобный и визуально приятный погодный сервис, где пользователь за пару секунд получает **всю важную информацию о погоде в нужном городе**.
